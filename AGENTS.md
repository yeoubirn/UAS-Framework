# Narendra Media

Tugas UAS Workshop Pemrograman Framework. Lihat BRIEF.md untuk fitur, tabel, dan tampilan.

## Stack
Laravel 12, Blade, Tailwind (via Breeze), SQLite.

## Aturan
- Ikuti BRIEF.md. Jangan menambah fitur atau tabel di luar BRIEF.md.
- Kerjakan HANYA sprint yang diminta, lalu BERHENTI dan tunggu perintah berikutnya.
- Kode sederhana dan mudah dijelaskan mahasiswa. Hindari abstraksi berlebihan (tanpa service layer, repository, atau package tambahan).
- Pakai Eloquent relationships, Form Request untuk validasi, resource controller.
- Label UI Bahasa Indonesia, nama class/variabel Bahasa Inggris.
- Setelah selesai, sebutkan file yang dibuat/diubah dan cara mengujinya.
